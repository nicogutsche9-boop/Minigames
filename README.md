# 🎮 Mini Arcade

Eine kleine Sammlung von Minigames,
entwickelt mit HTML, CSS und JavaScript.

## 🎯 Aktuelle Spiele

- ⚡ Reaction

## 🚧 Geplant

- 🧠 Memory
- 🐍 Snake
- 🔢 Higher or Lower
- 🎯 Aim Trainer
- 🧮 Math Rush

## 🛠 Technologien

- HTML5
- CSS3
- JavaScript
- ES Modules

## 🚀 Starten

Das Projekt benötigt keinen Build-Prozess.

Einfach `index.html` über einen lokalen Webserver öffnen.

Zum Beispiel mit VS Code und Live Server.

## 🌐 Deployment

Das Projekt kann über GitHub Pages veröffentlicht werden.
